# mapciety
On maps and data, and on data on maps.

| Folder | Project |
|---|---|
| [`town-or-cow`](town-or-cow) | Urban or rural? A model that classifies Swiss and Hungarian municipalities, trained in one country and tested in the other |
| [`sound-shadow`](sound-shadow) | A vertical sound map of Elephant & Castle, London: road noise per floor, and how much quieter it is behind tall buildings |

Each folder has its own README, scripts and `requirements.txt`. Downloaded data stays on your computer and is not uploaded to GitHub.
